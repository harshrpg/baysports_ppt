# Baysports payments presentation

An animated, browser-based presentation for Baysports owners and operations. It turns the detailed payments and invoice-management design into a concise decision story.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3010`.

## Present

- `←` / `→`, Page Up / Page Down, or Space: navigate
- `N`: show or hide speaker notes
- `O`: open the slide navigator
- `S`: open sources and assumptions
- `F`: enter full screen
- `Esc`: close an open panel

The deck is designed for a 16:9 screen and scales down for tablets and laptops. Interactive controls on the customer, exception, and decision slides can be clicked during the presentation.

## Story source

The content is distilled from `baysports-payments-and-invoice-management-design.md` in the Baysports repository. Supplier prices and delivery figures remain planning assumptions until provider quotes and the outstanding business decisions are confirmed.
